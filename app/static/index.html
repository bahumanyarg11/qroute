The problem
01 / 04 · Normal day

Shortest path works — while the network is quiet.

Every flow takes its shortest route. Links stay green and nobody notices the routing at all.

02 / 04 · Rush hour

A +50% surge piles traffic onto the same links.

Shortest-path weights never look at load, so busy links get busier while detours sit idle.

03 / 04 · Fibre cut

One cut fibre — and packets start to drop.

Re-convergence pushes everything onto the next shortest link. Two links go past capacity: 2.18 Gbps is lost.

04 / 04 · Q-Route

Q-Route spreads the load. Nothing is dropped.

The quantum-inspired optimizer re-plans all 30 flows together in 0.4 s. Busiest link: 82%.

How it works

How Q-Route decides.

A quantum-inspired evolutionary algorithm (QIEA): superposition, measurement and rotation gates — simulated on a CPU, no quantum hardware needed.

Explainer clip is rendering…
01

Superposition

Every flow has 8 candidate paths. Three Q-bits encode them, each starting halfway between 0 and 1 — so the register holds every combination at once.

|ψ⟩ = cos θ |0⟩ + sin θ |1⟩
02

Measurement

Sampling each Q-bit (P(1) = sin²θ) collapses the register into one concrete route per flow. We take 16 samples per generation.

101 → path 5 · 010 → path 2 · 110 → path 6
03

Scoring

Each sampled route set gets one number that balances delay, the busiest link and lost traffic. Lower is better.

J = L + 100·max(0, MLU − 0.8) + 50·Drop
04

Rotation gate

Every Q-bit is turned slightly toward the best route set so far. After 300 generations the register has converged; if it stalls, tunnelling re-opens superposition.

U(Δθ) = [cos Δθ −sin Δθ ; sin Δθ cos Δθ], Δθ = 0.025π
Safety by design

The LLM explains. It never routes.

Why it wins —
…
Same core, different encodersEvery domain uses the identical QIEA loop — superposition, measurement, scoring, rotation. Only the meaning of the Q-bits and the cost function change.
Always against a baselineEach result is compared with the classical method people actually use first: nearest-neighbour routing, greedy folding, per-site best fit, greedy rostering.
Honest scaleThese are small, synthetic proof-of-concept models — optimisation demos, not real drug discovery, protein prediction or clinical scheduling.

Scales linearly

The honest trade-offQ-Route's average delay is about 1 ms higher: it uses longer, idle paths so that nothing is dropped.
